## 4. 核心功能实现

- 密码生成算法：基于用户选择的字符类型和长度生成随机密码
- 字符集：
  - 小写字母：a-z
  - 大写字母：A-Z
  - 数字：0-9
  - 特殊符号：!@#$%^&*()_+-=[]{}|;:,.<>?
- 复制功能：使用 Clipboard API
